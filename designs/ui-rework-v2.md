## 1. 总纲与竞品范式（v1 §0/§1 修订）

**做成一个聊天产品，不是一个仪表盘。** 核心对象=对话。且比 v1 多一层：**主读面必须是消息，不是事件日志**（P1-07）；一切实现细节退到后台，但业务失败/未知结果/待答**不可消失**（安全可见性优先于整洁）。

| 环节 | 现状 | 目标范式（来源=ChatGPT/Claude/LibreChat 2026-10 通行结构；参照范式非像素复刻） |
|---|---|---|
| 新建会话 | 表单 | **直接开聊**：新对话=输入框+模型待发配置；首条消息发出即建会话 |
| 连接状态 | 三格常驻 | **全局健康点**三档+点开明细（唯一恢复入口，R1 必需） |
| 会话列表 | 平铺 | **时间四分组+「加载更多」续页**（不做假完整列表） |
| 模型 | 只在新建表单 | **新建时选待发模型**；已有会话不显示假当前模型，给「换模型开新对话」入口（契约事实：运行中会话 model 仅下次冷启动生效，contracts v1.4:475） |
| 手机端 | 上下挤一屏 | **两视图切换**，业务订阅与可见性解耦 |
| 空态 | 一行字 | **中央大输入框**=新对话编辑器本体（不另造第二套状态） |

## 2. 组件面

### 2.1 退役
- `NewSession` 表单壳（autoFile/readLastModel/writeLastModel/isPersistableModel/__ 哨兵守卫**全部抽出保留**，P2-3）
- `connbar` 三格（被 HealthDot 替代）

### 2.2 新增
- **`HealthDot`**（顶栏角落 button，aria-label=状态文本）：确定性聚合——认证受控面（authFailed）优先显示；三面全 ready=绿；三面全终态 down=红；其余（初连/握手/部分断/重连中）=黄+「连接中/重连中/部分不可用」文本。点开浮层=三面明细+立即重连钮（沿用壳层退避，不叠 timer）；**绿也可点开**；Esc/外点关闭+焦点归还；无纯颜色判断。
- **`EmptyConversation`**（新对话态）：Welcome 与本组件**合并为同一受控编辑器**（P1-01：聚焦只是聚焦，不创建新 draft；首次字符/IME 组合/待发模型完整带过首链）。桌面空态与新建态仅 header 文案差异。
- **`ConversationHeader`**：返回钮（手机）+标题+「换模型开新对话」入口；**loading/error/empty/streaming 全状态常驻**（P2-4）；标题与列表同源（resolveTitle）。
- **`Sidebar`**：「＋ 新对话」大按钮+分组列表+续页。

### 2.3 生命周期与状态归属（P1-01 核心）
订阅、业务操作、可见页=**三套生命周期**。state 归属：
- `RealApp` 层持有：view（list/conversation，仅手机语义化）、活动 file、draftId、草稿（autoFile+文本版本+模型待发值+发起 client 身份）、重连壳层状态。**不放重连会卸载的分支**（v1 的 ConnectedApp 内 newSession 布尔即此错误）。
- 活动会话订阅控制器：与可见页解耦（§2.4）。

### 2.4 订阅保活（P0-02 修法）
- 手机返回列表/断点 767↔768 切换：**仅切可见性**（hidden 页 `visibility:hidden` 或卸载呈现组件但保订阅 owner），不卸载订阅控制器，零 unsubscribe/stop/ui-answer 帧。
- 真换 file（选另一会话/进新对话）：旧订阅退出；**若旧会话有待答 ui-request，显式提示**（「离开将取消待答问题」确认）不得沉默取消。
- 被隐藏页面不可聚焦、不暴露读屏（inert）。

### 2.5 主读面分层（P1-07）
- `SessionDetail` 改造：默认读面=你/助手消息（HistoryRow 中消息型事件）；turn-enqueued/sending/判决/工具类事件入**二级「活动详情」区**（摘要行+展开，复用现有 EntryFrame 展开通道）。
- WriteComposer 常驻的原始 intentId/generation 手输恢复框→移入「高级诊断」折叠区（核心聊天任务不暴露）。
- 直播最终正文落历史**只显示一次、不消失**（直播态与历史态互斥合并）；安全/未知结果/待答提示保留可见。
- 不发明新消息协议；无稳定配对证据不猜配对、不删事件。

### 2.6 列表续页（P1-08）
- 用现有 offset/limit 帧（协议已支持，handleList 回 hasMore）实现「加载更多」前端链：累计去重+稳定排序（lastActiveMs desc+file 次键）+listVersion 变化一致刷新；失败可重试；显示「已载 N/共 M」部分载入事实。
- 不跨版本拼伪完整列表。

### 2.7 空态文案（P3-2）
桌面=「从左侧继续或直接开始新对话」；手机列表页=「点会话继续」。不造两套业务状态。

## 3. 状态与交互细则

### 3.1 页面状态表（P1-01）
```
顶层：list | draft | session(file)      —— 三互斥主态（桌面为投影：sidebar+main 组合）
叠加：editing | sending | rejected | unknown —— 草稿/发送叠加态
```
- 草稿对象：`{draftId, autoFile(稳定), textVersion, model(待发), clientId}`。**autoFile 在草稿创建时即定**（CSPRNG 既有），非 launched 才知；write-ack 只回显所发 file。新建下一份草稿才换 file；重试同份不换。
- 手机初始 view=list；点新对话/会话→conversation。重连保留 view/活动 file/未发送草稿；在途效果按未知处理，**不自动重发**。
- 迟到回执：只有操作身份（client×file/draftId×文本版本）匹配当前页面意图才允许切页；旧回执可触发列表刷新，不得把 B 会话/新草稿抢回 A。

### 3.2 发送结果语义（P1-02）
| 结果 | 显示 | 清稿 | 出口 |
|---|---|---|---|
| launched | 已启动/已受理（不写「完成」） | **仅三元身份匹配才清** | 进会话详情 |
| 明确拒收（busy/gate-rejected/invalidated/identity-rejected/not-ready） | 受控原因 | **保全文+模型选择** | 显式重试/改配置 |
| gate-failed/传输失败/断线/回执超时 | **未知态**：可能已受理 | 保留操作身份和文本 | 查看/刷新/离场；显式二次发送须示「重复执行风险」；**禁自动重发、禁自动换 file、禁 UI 伪造协议失败** |
- 修 `use-write.ts:163` 任意合法 ack→true 的吞稿链：hook 返回结构化 outcome（前端内部类型，零服务端帧变更）。
- 首条与后续消息语义一致。prompt 与 stop 并行、停止仅显式触发——保持现有语义。

### 3.3 导航与待答（P0-02 细则）
见 §2.4。补充：桌面取消路径=返回按钮/侧栏点选同规则（换 file 有待答→提示；同 file 切 view→保活）。

### 3.4 健康点聚合表（P1-03）
| 条件 | 档位 | 文本 |
|---|---|---|
| 任一面 authFailed/token/跨源拒绝 | 受控面（不进自动重连，现安全门保持） | 认证失败/需重新进入 |
| 三面全 ready | 绿 | 已连接 |
| 三面全终态（closed/error 且无在途重连） | 红 | 连接断开 |
| 其余（含 connecting/handshake/部分 down/退避等待） | 黄 | 连接中/重连中/部分不可用 |
- 健康点只述传输健康，不暗示模型可用/订阅正常/上一条完成；业务拒绝在消息/页面局部显示。
- 手动重连提示「未决写操作不会自动补发」。

### 3.5 键盘/IME/滚动（P1-04，v1 事实错误已纠）
- Enter 发送/Shift+Enter 换行：**本批在真 write-composer 实现**（现无 onKeyDown）；IME composing（keyCode 229）不发送；只在 canSend 时处理并阻止重复；软键盘无可靠 Enter→可见发送钮常驻。
- 列表打开→标题/编辑器合理聚焦；返回→原条目/新建钮+列表滚动位置恢复。
- 流式更新仅在用户贴底时跟随滚动；向上读旧不被强拉到底。
- 手机动态视口/安全区下输入/停止/待答可达。

### 3.6 分组与时间（P2-1）
四互斥组：今天 `[D0,+∞)`；昨天 `[D-1,D0)`；过去 7 天 `[D-7,D-1)`；更早。**本地自然日边界**（非 24h×n 减法）；未来时间归「今天」；lastActiveMs=null 归「更早」。测试冻结时钟测 D0/D-1/D-7 恰好边界+DST+null；跨午夜/回前台刷新相对时间；timer 卸载清理。

### 3.7 列表状态不回退（P2-2）
保留 loading/empty/error/auth-failed/closed、选中 aria-current、同源 resolveTitle、手动刷新、partial/recovery 信息可发现性；删「当前版本不自动重连，刷新页面」陈旧文案。

## 7. 风险与边界

- 模型真值缺失：SessionSummaryDTO 无实际模型字段——已有会话诚实显示「模型未知」而非伪造（契约批另立时再议实时下发）。
- 离场取消待答：导航面修（保活）；跨全部会话待答重放不在本批（现单活动订阅架构，另立契约批）。
- 回执未知态：P1-02 语义已定，防吞稿+防重复双门。
- 首页截断：续页已入 R1。
- 缓存旧构建：验收记真实构建 ID（html+asset 同切）；曾有「源码删表单用户仍见旧面」教训。
- 服务端零改动红线：仅前端 hook/客户端装配可调；任何协议/帧结构/服务端变更=越界即停。
